# Matrix Chain Multiplication Using Dynamic Programming

## Problem Statement

Implement the **Matrix Chain Multiplication** algorithm using Dynamic Programming.

Given the dimensions of `N-1` matrices in an array `arr[]`, determine the **minimum number of scalar multiplications** required to multiply the complete matrix chain.

The objective is to find the most efficient order of multiplying the matrices so that the total number of scalar multiplications is minimized.

---

## Objective

Given an array `arr[]` of size `N`, the matrices are formed as follows:

- Matrix `A1` has dimensions `arr[0] x arr[1]`
- Matrix `A2` has dimensions `arr[1] x arr[2]`
- Matrix `A3` has dimensions `arr[2] x arr[3]`
- And so on.

Therefore, `N` dimensions represent `N-1` matrices.

The order of the matrices cannot be changed. Only the **parenthesization (order of multiplication)** can be changed.

---

## Example

For:

`N = 4`

`arr[] = {10, 30, 5, 60}`

The matrices are:

- `A1 = 10 x 30`
- `A2 = 30 x 5`
- `A3 = 5 x 60`

There are two possible ways to multiply these three matrices.

### Option 1

`(A1 x A2) x A3`

Cost of `A1 x A2`:

`10 x 30 x 5 = 1500`

The resulting matrix has dimensions `10 x 5`.

Cost of the second multiplication:

`10 x 5 x 60 = 3000`

Total cost:

`1500 + 3000 = 4500`

### Option 2

`A1 x (A2 x A3)`

Cost of `A2 x A3`:

`30 x 5 x 60 = 9000`

The resulting matrix has dimensions `30 x 60`.

Cost of the second multiplication:

`10 x 30 x 60 = 18000`

Total cost:

`9000 + 18000 = 27000`

Therefore, the minimum number of scalar multiplications is:

`4500`

---

## Dynamic Programming Approach

We use Dynamic Programming to avoid calculating the same subproblems repeatedly.

Define:

`dp[i][j]`

as the minimum number of scalar multiplications required to multiply matrices from `Ai` to `Aj`.

For every possible position `k` between `i` and `j`, we consider splitting the matrix chain into two parts:

- Matrices `Ai` to `Ak`
- Matrices `A(k+1)` to `Aj`

The cost of this split is:

`dp[i][k] + dp[k+1][j] + arr[i-1] x arr[k] x arr[j]`

We calculate this for every possible `k` and choose the minimum.

---

## Recurrence Relation

The recurrence relation is:

`dp[i][j] = min(dp[i][k] + dp[k+1][j] + arr[i-1] x arr[k] x arr[j])`

where:

`i <= k < j`

---

## Base Condition

When there is only one matrix, no multiplication is required.

Therefore:

`dp[i][i] = 0`

---

## DP Table

The DP table stores the minimum multiplication cost for different sections of the matrix chain.

For example:

`dp[1][2]`

represents the minimum cost of multiplying `A1` and `A2`.

Similarly:

`dp[1][3]`

represents the minimum cost of multiplying `A1`, `A2`, and `A3`.

The final answer is stored in:

`dp[1][N-1]`

---

## Algorithm

1. Read the value of `N`.
2. Read the `N` dimensions into the array `arr[]`.
3. The number of matrices is `N-1`.
4. Create a 2D DP table of size `N x N`.
5. Initialize `dp[i][i] = 0` for all matrices.
6. Consider matrix chains of length 2, 3, and so on.
7. For each chain, try every possible splitting position `k`.
8. Calculate the multiplication cost for each split.
9. Store the minimum cost in `dp[i][j]`.
10. Continue until the complete matrix chain has been processed.
11. The value `dp[1][N-1]` gives the minimum number of scalar multiplications.
12. Display the result.

---

## Why Dynamic Programming?

A recursive solution can try every possible parenthesization of the matrix chain. This results in a very large number of repeated calculations.

Dynamic Programming stores the results of smaller matrix chains and reuses them when solving larger chains.

This significantly improves the efficiency of the algorithm.

---

## Complexity Analysis

### Time Complexity

There are three nested loops:

- One loop for the chain length.
- One loop for the starting matrix.
- One loop for trying every possible split.

Therefore:

`Time Complexity = O(N^3)`

### Space Complexity

The algorithm uses a 2D DP table of size `N x N`.

Therefore:

`Space Complexity = O(N^2)`

---

## Key Points

- `N` dimensions represent `N-1` matrices.
- Matrix order cannot be changed.
- Only the parenthesization can be changed.
- The goal is to minimize the number of scalar multiplications.
- `dp[i][j]` stores the minimum cost of multiplying matrices `Ai` through `Aj`.
- A single matrix requires `0` multiplications.
- The final answer is stored in `dp[1][N-1]`.
- Time Complexity: `O(N^3)`
- Space Complexity: `O(N^2)`

---

## Conclusion

Matrix Chain Multiplication is an optimization problem that can be efficiently solved using Dynamic Programming.

By considering every possible way to split the matrix chain and storing the minimum cost of smaller chains, the algorithm finds the optimal multiplication order.

For the example:

`arr[] = {10, 30, 5, 60}`

the minimum number of scalar multiplications required is:

`4500`

The final complexity of the algorithm is:

`Time Complexity = O(N^3)`

`Space Complexity = O(N^2)`
