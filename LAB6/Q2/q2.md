# 0/1 Knapsack Problem Using Dynamic Programming

## Problem Statement

Implement the 0/1 Knapsack problem using Dynamic Programming.

Given `n` items, where each item has a weight and a profit, and a knapsack with maximum capacity `W`, determine the maximum profit that can be obtained.

Each item can either be included or excluded from the knapsack. An item can be selected at most once.

## Objective

Find a combination of items such that:

- The total weight does not exceed the knapsack capacity `W`.
- The total profit is maximum.
- Each item is selected at most once.

## Input

The program takes the following input from the user:

1. Number of items `n`
2. Weight of each item
3. Profit of each item
4. Maximum capacity of the knapsack `W`

## Output

The program displays the maximum profit that can be obtained without exceeding the knapsack capacity.

## Approach

The problem is solved using Dynamic Programming.

We define a DP table:

`dp[i][w]`

where:

- `i` represents the number of items considered.
- `w` represents the current knapsack capacity.
- `dp[i][w]` represents the maximum profit that can be obtained using the first `i` items with capacity `w`.

For every item, there are two choices:

### 1. Exclude the Item

If the current item is not selected, the maximum profit remains the same as the previous row:

`dp[i][w] = dp[i-1][w]`

### 2. Include the Item

If the weight of the current item is less than or equal to the current capacity, the item can be included.

The profit becomes:

`profit[i-1] + dp[i-1][w-weight[i-1]]`

We use `i-1` in the DP table because an item can be selected only once.

Therefore, the recurrence relation is:

`dp[i][w] = max(dp[i-1][w], profit[i-1] + dp[i-1][w-weight[i-1]])`

If the current item's weight is greater than the available capacity, the item cannot be included:

`dp[i][w] = dp[i-1][w]`

## Algorithm

1. Read the number of items `n`.
2. Read the weight of each item.
3. Read the profit of each item.
4. Read the knapsack capacity `W`.
5. Create a DP table of size `(n+1) x (W+1)`.
6. Initialize the first row and first column with `0`.
7. Iterate through each item.
8. For each item, iterate through every possible capacity from `1` to `W`.
9. If the item's weight is greater than the current capacity, exclude the item.
10. Otherwise, calculate:
    - Profit when the item is excluded.
    - Profit when the item is included.
11. Store the maximum of the two values in the DP table.
12. The value `dp[n][W]` contains the maximum possible profit.
13. Display the maximum profit.
14. Free the dynamically allocated memory.

## DP Table

The DP table represents the maximum profit for different numbers of items and different knapsack capacities.

The rows represent the number of items considered, while the columns represent the available capacity.

The final cell:

`dp[n][W]`

contains the maximum possible profit.

## Complexity Analysis

### Time Complexity

The DP table has `(n+1) x (W+1)` entries.

Each entry is calculated in constant time.

Therefore:

`Time Complexity = O(nW)`

### Space Complexity

The DP table requires `(n+1) x (W+1)` memory locations.

Therefore:

`Space Complexity = O(nW)`

## Comparison with Brute Force

In the brute-force approach, every possible subset of items is considered.

For `n` items, the number of possible subsets is:

`2^n`

Therefore, the brute-force approach has:

`Time Complexity = O(2^n)`

The Dynamic Programming approach improves this to:

`Time Complexity = O(nW)`

by storing the results of previously solved subproblems and reusing them.

## Why Is It Called 0/1 Knapsack?

It is called the 0/1 Knapsack problem because every item has only two possible choices:

- `0` → Item is not selected.
- `1` → Item is selected.

An item cannot be partially selected and cannot be selected more than once.

## Key Points

- Each item can be selected at most once.
- The total weight must not exceed the knapsack capacity.
- The objective is to maximize total profit.
- Dynamic Programming is used to avoid solving the same subproblems repeatedly.
- The final answer is stored in `dp[n][W]`.
- The time complexity is `O(nW)`.
- The space complexity is `O(nW)`.

## Conclusion

The 0/1 Knapsack problem can be efficiently solved using Dynamic Programming by considering two choices for every item: include the item or exclude the item.

By storing the results of smaller subproblems in a DP table, repeated calculations are avoided.

The Dynamic Programming solution has a time complexity of `O(nW)` and a space complexity of `O(nW)`, which is more efficient than the exponential brute-force approach for suitable values of `n` and `W`.
