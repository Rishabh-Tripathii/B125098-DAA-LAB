# Maximum Scientists Alive — Event Sorting

## 📌 Problem Statement

Given `n` scientists, each with a **birth year** and a **death year**, determine:

1. The **maximum number of scientists alive at the same time**.
2. The **year when this maximum occurs**.

Each scientist contributes an interval of time between their birth and death.

The problem can be solved efficiently by treating every birth and death as an **event** and processing these events in chronological order.

---

## 🧠 Approach

Instead of checking every year individually, we create two events for every scientist:

* **Birth event** → `+1`
* **Death event** → `-1`

For example, conceptually:

```text
Birth → +1
Death → -1
```

All `2 × n` events are then sorted by year.

While traversing the sorted events, we maintain:

```c
alive
```

which represents the current number of scientists alive.

For every event:

```c
alive += events[i].type;
```

If a birth occurs, the number of living scientists increases.

If a death occurs, it decreases.

Whenever `alive` becomes greater than the previous maximum, we store:

```c
maxAlive = alive;
bestYear = events[i].year;
```

---

## 🔄 Handling the Same Year

An important part of the solution is handling a birth and death occurring in the **same year**.

The program sorts events using:

```c
return e1->type - e2->type;
```

when the years are equal.

Since:

```text
Death = -1
Birth = +1
```

the death event is processed **before** the birth event.

Therefore, if one scientist dies in a particular year and another is born in that same year, the program does not count both as simultaneously alive at that point.

This ordering is implemented in `compareEvents()`.

---

## 📊 Algorithm

1. Read the number of scientists.
2. Create two events for each scientist:

   * `(birth year, +1)`
   * `(death year, -1)`
3. Sort all events by:

   * Year in ascending order.
   * Death before birth when years are equal.
4. Initialize:

   ```text
   alive = 0
   maxAlive = 0
   ```
5. Traverse all sorted events.
6. Update the current number of living scientists.
7. Whenever the current count exceeds `maxAlive`, update the maximum and corresponding year.
8. Print the maximum number of scientists alive and the year at which it occurs.

---

## ⏱️ Complexity Analysis

There are `2n` events.

Sorting the events takes:

```text
O(n log n)
```

Traversing all events takes:

```text
O(n)
```

Therefore, the overall complexity is:

```text
Time Complexity:  O(n log n)
Space Complexity: O(n)
```

The `O(n)` space is used to store the `2n` birth and death events.

## 💡 Why This Approach?

A naive solution could examine every possible year and count how many scientists were alive during that year. This becomes inefficient when the range of years is large.

The **event-based sweep-line approach** only considers years where the population can change—births and deaths.

Thus, instead of processing every year, we process only `2n` relevant events, giving an efficient `O(n log n)` solution.
