# Switch Toggle Problem — Recursion

## 📌 Problem Statement

Given `n` switches, initially all switches are **ON**. The goal is to turn all switches **OFF** using a sequence of valid toggle operations.

The program uses **recursion** to determine the required sequence of switch toggles and prints the state after every move.

---

## 🧠 Approach

The solution uses a recursive strategy based on solving smaller groups of switches first.

For `n > 2`:

1. Solve the first `n-2` switches.
2. Toggle switch `n`.
3. Clear the remaining `n-1` switches using the `clearSwitches()` recursive function.

The main recursive function is:

```c
solve(n, total);
```

### Base Cases

For one switch:

```text
toggle(0)
```

For two switches:

```text
toggle(1)
toggle(0)
```

For larger values, the problem is reduced recursively.

---

## 🔄 `clearSwitches()` Function

The function:

```c
clearSwitches(m, n)
```

is used to turn a group of switches OFF when the required starting configuration has the appropriate recursive form.

Its recurrence is:

```text
CLEAR(m) =
    CLEAR(m-1)
    toggle(m)
    CLEAR(m-1)
```

This gives the recursive structure needed to clear the remaining switches.

---

## 📊 State Representation

The switches are stored in:

```c
int sw[MAX];
```

where:

```text
0 = OFF
1 = ON
```

Switch `0` represents the **rightmost switch**.

The `printState()` function prints the switches from left to right.

Every toggle is counted using:

```c
long long moves;
```

---

## ⏱️ Complexity

The recursive solution generates an exponential number of moves.

```text
Time Complexity:  O(2^n)
Space Complexity: O(n)
```

`O(n)` space is required primarily for the recursion stack and switch array.

## 📝 Summary

The program recursively transforms a configuration in which all switches are **ON** into one in which all switches are **OFF**. It tracks every toggle, prints each intermediate state, and reports the total number of moves performed.
