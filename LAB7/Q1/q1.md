Coin Triangle Inversion

Problem

Given an equilateral triangle formed by n rows of coins, invert the triangle by moving one coin at a time to a new position.

Example for n = 5:

        O
      O O
    O O O
  O O O O
O O O O O

Target:

O O O O O
  O O O O
    O O O
      O O
        O

The objective is to perform the inversion using the minimum possible number of moves.

Input

The program takes the number of rows n as input.

Output

The program displays:

the initial triangle,

the selected target configuration,

every actual coin movement,

the board after each move,

the final inverted triangle,

the total number of moves.

Approach

Each coin is represented by its position on the triangular grid:

typedef struct {
    int row;
    int x;
} Coin;

The algorithm:

Creates the original triangle.

Generates possible inverted-triangle target configurations.

Compares source and target positions.

Selects the configuration requiring the fewest moved coins.

Leaves coins already in target positions unchanged.

Moves the remaining coins to empty target positions.

Counts and displays every actual move.

Prints the final inverted triangle.

Minimum Moves

For n rows, the minimum number of moved coins is:

[
M(n) = \left\lfloor \frac{n(n+1)}{6} \right\rfloor
]

For n = 5:

[
M(5) = \frac{5(6)}{6} = 5
]

Thus, the 5-row triangle requires 5 moves.

Algorithm

START

Read n

Create the original triangle

For every possible target position:
    Create the inverted triangle
    Find positions common to source and target
    Count coins that need to move

Select the target requiring the minimum moves

For each coin not already in a target position:
    Find an empty target position
    Move the coin there
    Increment the move counter
    Display the current configuration

Display the final inverted triangle
Display total moves

END

Example

Input:

Enter number of rows: 5

Initial:

        O
      O O
    O O O
  O O O O
O O O O O

Final:

O O O O O
  O O O O
    O O O
      O O
        O

Result:

Total moves performed = 5

Complexity Analysis

There are:

[
1+2+\cdots+n = \frac{n(n+1)}2 = O(n^2)
]

coins.

The straightforward implementation repeatedly searches the stored coin positions when checking whether a position is occupied.

Therefore:

Time Complexity: O(n^4)

Space Complexity: O(n^2)

The mathematical formula alone can be evaluated in O(1), but this program actually searches configurations and performs the coin movements.
