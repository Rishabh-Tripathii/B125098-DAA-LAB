# Egg Dropping Problem — Dynamic Programming

## 📌 Problem Statement

The **Egg Dropping Problem** is a classic Dynamic Programming problem.

Given:

* `E` eggs
* `F` floors

The goal is to determine the **minimum number of egg drops required in the worst case** to find the highest floor from which an egg can be dropped without breaking.

### Example

If there are **2 eggs and 10 floors**, we need to find the minimum number of drops required to determine the critical floor in the worst case.

---

## 🧠 Approach

This solution uses **Dynamic Programming (DP)**.

We define:

```text
dp[e][f] = minimum number of drops required
           using e eggs and f floors
```

For every possible floor `x` from which we can drop an egg, there are two possible outcomes.

### 1. Egg Breaks

If the egg breaks at floor `x`:

```text
dp[e - 1][x - 1]
```

We are left with:

* `e - 1` eggs
* `x - 1` floors below the current floor

### 2. Egg Survives

If the egg does not break:

```text
dp[e][f - x]
```

We still have:

* `e` eggs
* `f - x` floors above the current floor

### Worst Case

Since we don't know which outcome will occur, we consider the worse of the two:

```text
1 + max(dp[e - 1][x - 1], dp[e][f - x])
```

The `1` represents the current egg drop.

We try every possible floor `x` and choose the minimum among all possible choices:

```text
dp[e][f] =
    min(
        dp[e][f],
        1 + max(dp[e - 1][x - 1], dp[e][f - x])
    )
```

---

## 🔹 Base Cases

The DP table is initialized using three important cases.

### 0 Floors

If there are no floors, no drops are required:

```text
dp[e][0] = 0
```

### 1 Floor

With one floor, only one drop is required:

```text
dp[e][1] = 1
```

### 1 Egg

If only one egg is available, we have to test the floors sequentially:

```text
dp[1][f] = f
```

For example:

```text
1 egg + 5 floors → 5 drops
```

---

## 🔄 Algorithm

1. Create a DP table of size `(E + 1) × (F + 1)`.
2. Initialize the base cases.
3. For each number of eggs from `2` to `E`:

   * For each number of floors from `2` to `F`:

     * Try dropping the egg from every floor `x`.
     * Calculate the number of drops if the egg breaks.
     * Calculate the number of drops if the egg survives.
     * Take the worst-case result.
     * Store the minimum result.
4. Return `dp[E][F]`.
5. Free the dynamically allocated memory.

## 📊 Example

### Input

```text
Enter number of eggs: 2
Enter number of floors: 10
```

### Output

```text
Minimum number of drops = 4
```

The answer is `4` because, with optimal choices, the critical floor can always be determined within **4 drops in the worst case**.

## ⏱️ Complexity Analysis

Let:

* `E` = number of eggs
* `F` = number of floors

There are `E × F` DP states.

For every state, the program tries every possible floor `x`.

Therefore:

### Time Complexity

```text
O(E × F²)
```

### Space Complexity

```text
O(E × F)
```

The space is required to store the 2D DP table.

---

## 💡 Why Dynamic Programming?

A brute-force recursive solution repeatedly solves the same subproblems.

For example:

```text
eggDrop(e, f)
```

can recursively call:

```text
eggDrop(e - 1, x - 1)
eggDrop(e, f - x)
```

for multiple values of `x`.

This causes many repeated calculations.

Dynamic Programming avoids this by storing already-computed results in:

```text
dp[e][f]
```

So each subproblem is solved only once.

## 📐 Recurrence Relation

For `e ≥ 2` and `f ≥ 2`:

```text
dp[e][f] = min over x=1...f {
    1 + max(
        dp[e-1][x-1],
        dp[e][f-x]
    )
}
```

Where:

* `x` = floor from which the egg is dropped
* `dp[e-1][x-1]` = egg breaks
* `dp[e][f-x]` = egg survives
* `1` = current drop

## 👨‍💻 Summary

This program solves the classic **Egg Dropping Problem** using Dynamic Programming.

The key idea is to try every possible dropping floor and consider both possible outcomes:

```text
Egg Breaks    → Check lower floors with fewer eggs
Egg Survives  → Check higher floors with the same number of eggs
```

Since we need a solution that works in the **worst case**, we take the maximum of these two outcomes and then choose the floor that minimizes this worst-case number of drops.
