# Hiding Spot Target Problem — Simulation

## 📌 Problem Statement

There are `n` hiding spots arranged in a line. A target is initially hidden at an unknown position.

In each round:

1. A position is selected and searched.
2. If the target is at that position, it is hit.
3. If the target survives, it can move to an adjacent position.

The objective is to determine a sequence of shots that **guarantees the target will eventually be hit**, regardless of its initial position and movements.

---

## 🧠 Approach

The program uses a **possible-state simulation**.

```c
possible[i] = 1
```

means the target could currently be at position `i`.

Initially, every position is possible:

```text
{ 1, 2, 3, ..., n }
```

After every shot:

1. The searched position is removed from the set of possible positions.
2. All surviving possible positions are moved to their adjacent positions.
3. The resulting positions become the new possible states.

This continues until no possible position remains.

---

## 🎯 Search Strategy

For `n > 2`, the program uses two sweeps.

### First Sweep

The program searches from:

```text
2, 3, 4, ..., n-1
```

### Second Sweep

It then searches in the reverse direction:

```text
n-1, n-2, ..., 2
```

This movement of the search position prevents the target from continuously avoiding the searched locations.

The special case `n = 2` uses:

```text
1, 1
```

as its search sequence.

---

## 🔄 Movement Simulation

For every possible target position `i`, the program adds:

```text
i - 1
i + 1
```

when those positions exist.

This is implemented using the `next[]` array:

```c
if (i > 1)
    next[i - 1] = 1;

if (i < n)
    next[i + 1] = 1;
```

Thus, `possible[]` represents the current state while `next[]` stores the state after movement.

---

## 📊 Guarantee Condition

After every shot, the program counts the remaining possible positions.

If:

```text
remaining == 0
```

then there is no position where the target can still exist.

Therefore:

```text
Target is GUARANTEED to be hit.
```

---

## ⏱️ Complexity

For each shot, the program scans all `n` positions to:

* Remove the shot position.
* Count remaining states.
* Calculate the next possible states.

The number of shots is `O(n)`.

Therefore:

```text
Time Complexity:  O(n²)
Space Complexity: O(n)
```

---

## 🧩 Key Concepts

* State-space simulation
* Boolean state representation
* Greedy search sequence
* Set/state transitions
* Adjacency-based movement
* Worst-case reasoning
* Simulation

## 📝 Summary

The program models **all positions where the target could possibly be**, rather than trying to predict the target's exact location.

After each shot and movement, the possible-state set is updated. A forward and backward sweep of search positions is used to eliminate all possible target locations and guarantee a hit.
