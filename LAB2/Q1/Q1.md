# Dictionary Operations – DAA Experimental Analysis

## Overview

This project implements a Dictionary Abstract Data Type (ADT) using six different data structures and experimentally compares their performance.

### Data Structures

1. Unsorted Array
2. Sorted Array
3. Singly Linked List – Unsorted
4. Singly Linked List – Sorted
5. Doubly Linked List – Unsorted
6. Doubly Linked List – Sorted

## Operations Implemented

The following dictionary operations are implemented for each data structure:

- Search
- Insert
- Delete
- Minimum
- Maximum
- Predecessor
- Successor

The program counts the number of operations performed using an `operations` counter.
