# Merge Sort Comparison

## Overview

This C program compares the number of operations performed by standard two-way merge sort and modified three-way merge sort on randomly generated integer arrays. It records the operation counts for input sizes from 1000 to 10000 and stores the results in a CSV file.

## What the Program Does

- Generates random input arrays.
- Sorts one copy using standard merge sort.
- Sorts another copy using three-way merge sort.
- Counts the number of merge comparisons using the global `operations` counter.
- Writes the results to `merge_sort_comparison.csv`.

## Output File

After execution, the program creates:

- `merge_sort_comparison.csv`

The file has the format:

```csv
n,Normal Merge Sort,Three-Way Merge Sort
1000,...,...
2000,...,...
...
10000,...,...
```

## Compilation

Compile the program with GCC:

```bash
gcc -O2 merge_sort.c -o merge_sort
```

## Execution

Run the executable:

```bash
./merge_sort
```

The console output will display the number of operations for each input size and confirm creation of the CSV file.

## Algorithmic Complexity

### Standard Merge Sort

The recurrence is:

$$
T(n) = 2T(n/2) + O(n)
$$

Therefore, the worst-case running time is:

$$
O(n \log n)
$$

### Three-Way Merge Sort

The recurrence is:

$$
T(n) = 3T(n/3) + O(n)
$$

Therefore, the worst-case running time is also:

$$
O(n \log n)
$$

Although the three-way version has fewer recursion levels, its merge step usually requires more comparisons per output element, so both algorithms remain in the same asymptotic class.

## Important Correction

In the given code, the following call appears in `main()`:

```c
threeWayMergeSort(b, 0, n);
```

This should be changed to:

```c
threeWayMergeSort(b, 0, n - 1);
```

because valid array indices go from `0` to `n - 1`. Passing `n` may access memory out of bounds and produce incorrect results.

## Plotting the Results

A graph can be created from the CSV file using gnuplot.

Example script:

```gnuplot
set datafile separator ","
set terminal pngcairo size 1200,700
set output "merge_sort_comparison.png"
set title "Normal Merge Sort vs Three-Way Merge Sort"
set xlabel "Input Size (n)"
set ylabel "Operations"
set grid
plot "merge_sort_comparison.csv" using 1:2 with linespoints title "Normal Merge Sort", \
     "merge_sort_comparison.csv" using 1:3 with linespoints title "Three-Way Merge Sort"
```

## Notes

- The program measures comparison-like merge operations, not full wall-clock execution time.
- The exact counts may vary because the input is randomly generated using `rand()`.
- The graph should show that both algorithms grow on the order of $$n \log n$$.
