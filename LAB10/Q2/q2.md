# Number of Islands II — Dynamic Island Counting

## Problem
Given a grid of \(R\) rows and \(C\) columns, initially all cells are water. Land cells are added one by one through \(K\) operations.

After each operation, determine the number of distinct islands in the grid.

An island is a group of land cells connected horizontally or vertically (up, down, left, or right). Diagonal connections are not considered.

If a cell is already land, the operation does not create a new island, so the island count remains unchanged.

## Approach
Use the **Disjoint Set Union (DSU)** data structure with path compression and union by size to efficiently maintain connected islands.

Each grid cell is mapped to a unique one-dimensional index using:

\[
\text{id}(r,c)=r\times C+c
\]

Initially, every cell is marked as water using `parent[id] = -1`. When a cell becomes land, it is initialized as a separate component, and the island count increases by one.

Next, check its four adjacent cells. If an adjacent cell is already land, merge their components using DSU. Every successful merge combines two separate islands, so the island count decreases by one.

If the cell is already land, skip the insertion and report the existing island count.

## Algorithm
1. Read the grid dimensions \(R,C\) and the number of operations \(K\).
2. Allocate and initialize the `parent` and `size` arrays for all \(R\times C\) cells.
3. Set every cell to water and initialize the island count to zero.
4. For each land insertion \((r,c)\):
   - Validate the coordinates.
   - Convert the cell to its one-dimensional index.
   - If it is already land, print the current island count.
   - Otherwise, mark it as land, initialize its component size to one, and increment the island count.
   - Check its four neighbours.
   - For every neighbouring land cell, merge their components if they are different and decrement the island count after each successful merge.
   - Print the island count after the operation.
5. Free the dynamically allocated memory.

## Complexity Analysis
Let \(N=R\times C\) be the total number of grid cells.

- **Initialization Time:** \(O(N)\)
- **Processing Each Operation:** \(O(\alpha(N))\) amortized, because each operation checks four neighbours and performs a constant number of DSU operations.
- **Total Time Complexity:** \(O(RC+K\alpha(RC))\)
- **Space Complexity:** \(O(RC)\), for the parent and size arrays.

Here, \(\alpha(N)\) is the inverse Ackermann function, which grows extremely slowly and is effectively constant for practical input sizes.

## Key Concepts
- Disjoint Set Union (DSU)
- Path compression
- Union by size
- Dynamic connectivity
- Two-dimensional grid to one-dimensional indexing
