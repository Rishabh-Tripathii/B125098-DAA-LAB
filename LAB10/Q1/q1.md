# Online Graph Bipartiteness Testing

## Problem Description
A graph is called bipartite if its vertices can be divided into two disjoint sets such that every edge connects vertices belonging to different sets. An undirected graph is bipartite if and only if it contains no odd-length cycle.

In this problem, an undirected graph with `V` vertices receives `E` edges one by one. After each edge `(u, v)` arrives, we must determine whether adding it preserves the bipartite property.

If the new edge introduces an odd-length cycle, it must be rejected and the graph must remain unchanged. Otherwise, the edge is accepted. The process continues for all incoming edges.

## Approach
The graph is represented using an adjacency matrix. For every incoming edge `(u, v)`, the edge is temporarily added to the graph, and BFS is used to check whether the graph remains bipartite.

BFS assigns two colors, `0` and `1`, to the vertices such that every pair of adjacent vertices has different colors. If two adjacent vertices have the same color, the graph is not bipartite, so the newly added edge is removed. Otherwise, the edge is accepted.

The process also handles disconnected components by starting BFS from every uncolored vertex.

## Algorithm
1. Initialize an adjacency matrix with all entries set to `0`.
2. Read the number of vertices `V` and incoming edges `E`.
3. For each incoming edge `(u, v)`:
   - Temporarily add the edge to the adjacency matrix.
   - Initialize all vertex colors to `-1` (uncolored).
   - Perform BFS on every disconnected component.
   - Assign opposite colors to adjacent vertices.
   - If adjacent vertices have the same color, remove the newly added edge and report a bipartiteness violation.
   - Otherwise, accept the edge.
4. Display the final set of accepted edges.

## Time Complexity
For each incoming edge, BFS using an adjacency matrix takes \(O(V^2)\) time because every vertex's row is scanned.

For `E` incoming edges, the total worst-case time complexity is:

\[
\boxed{O(EV^2)}
\]
