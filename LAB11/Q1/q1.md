# Shortest Path on Parity-Constrained Graphs via 0-1 BFS

## 1. Problem Statement

Given a directed graph \(G=(V,E)\), a source vertex \(S\), and a non-negative penalty \(C\), each edge has a weight of either 0 or 1.

For every vertex \(v\), find the minimum effective cost of a path from \(S\) to \(v\).

The effective cost is defined as:

\[
\text{Cost}(P)=W(P)+
\begin{cases}
0 & \text{if } k_1(P)\text{ is even}\\
C & \text{if } k_1(P)\text{ is odd}
\end{cases}
\]

Where:
- \(W(P)\) is the sum of edge weights along the path.
- \(k_1(P)\) is the number of weight-1 edges in the path.
- \(C\) is the additional penalty for an odd number of weight-1 edges.

If a vertex is unreachable from \(S\), report it as unreachable.

## 2. Approach

The problem can be solved using **0-1 BFS with state expansion**.

A single distance value per vertex is insufficient because the final cost depends on whether the number of weight-1 edges is even or odd.

Therefore, maintain two distance values for each vertex:

- `dist[v][0]`: Minimum total edge weight to reach vertex \(v\) with even parity.
- `dist[v][1]`: Minimum total edge weight to reach vertex \(v\) with odd parity.

Initially, all distances are infinity, except `dist[S][0] = 0`, since the source is reached using zero weight-1 edges.

For every edge \((u,v)\) with weight \(w\), calculate the new parity as:

\[
p' = p \oplus w
\]

Here, \(\oplus\) denotes XOR. A weight-0 edge preserves parity, while a weight-1 edge flips it.

If the new distance improves the corresponding state, update it. Insert the state at the front of the deque when \(w=0\), or at the back when \(w=1\).

After processing all reachable states, calculate the final answer for every vertex:

\[
\text{answer}[v]=
\min\big(\text{dist}[v][0],\text{dist}[v][1]+C\big)
\]

If both states are unreachable, report the vertex as unreachable.

## 3. Algorithm

1. Initialize `dist[v][0]` and `dist[v][1]` to infinity for every vertex.
2. Set `dist[S][0] = 0` and insert the source state \((S,0)\) into the deque.
3. While the deque is not empty:
   - Remove the front state \((u,p)\).
   - Ignore it if its stored distance is outdated.
   - For every outgoing edge \((u,v)\) with weight \(w\):
     - Calculate `newParity = p XOR w`.
     - Calculate `newDistance = dist[u][p] + w`.
     - If `newDistance` is smaller than `dist[v][newParity]`, update the distance.
     - Insert the new state at the front if \(w=0\), otherwise at the back.
4. For every vertex, compute the minimum of the even-parity distance and the odd-parity distance plus penalty \(C\).
5. Report unreachable vertices when neither parity state is reachable.

## 4. Complexity Analysis

Let \(V\) be the number of vertices and \(E\) the number of directed edges.

**Time Complexity: \(O(V+E)\)**

The expanded graph contains \(2V\) states and at most \(2E\) transitions. Each state and transition is processed in constant time overall using 0-1 BFS, giving linear time complexity.

**Space Complexity: \(O(V+E)\)**

The adjacency list requires \(O(V+E)\) space. The distance array stores two values per vertex, and the deque stores expanded states, requiring \(O(V)\) and \(O(E)\) space respectively.

## 5. Conclusion

The problem is solved efficiently by combining state expansion with 0-1 BFS. Maintaining separate even- and odd-parity distances ensures that the penalty is applied correctly, while the deque processes edges of weight 0 and 1 efficiently. The resulting algorithm runs in linear time and space relative to the graph size.
