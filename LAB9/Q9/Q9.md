# README: Optimal Alphabetic Binary Tree

## Approach
The program constructs an optimal alphabetic binary tree using **Dynamic Programming** to minimize the weighted path length while preserving the original order of the weights.

The weighted path length is calculated as:

\[
WPL=\sum_{i=1}^{n} w_i d_i
\]

where \(w_i\) is the weight of the \(i\)-th leaf and \(d_i\) is its depth in the tree.

1. Compute prefix sums to calculate the sum of weights in any interval efficiently.
2. Use a DP table where `dp[i][j]` stores the minimum cost of constructing a tree from weights \(i\) through \(j\).
3. Try every possible split point \(k\) between \(i\) and \(j\).
4. Store the split point that produces the minimum cost.
5. Reconstruct the optimal tree using the `split` table.
6. Print the tree structure, leaf depths, and weighted contributions.

## Algorithm
1. Read the number of weights and validate that all weights are positive.
2. Calculate the prefix sum array.
3. Initialize `dp[i][i] = 0` because a single leaf requires no internal merging cost.
4. For each interval length from 2 to \(n\):
   - Iterate through all intervals of that length.
   - Calculate the interval weight sum using prefix sums.
   - Try every possible split \(k\).
   - Calculate the cost:

     \[
     dp[i][k]+dp[k+1][j]+\text{rangeSum}(i,j)
     \]

   - Store the minimum cost and its corresponding split point.
5. Print `dp[0][n-1]` as the minimum weighted path length.
6. Recursively reconstruct and print the optimal alphabetic binary tree.
7. Recursively print each leaf's depth and weighted contribution.

## Complexity Analysis

**Time Complexity: \(O(n^3)\)**

- Computing prefix sums: \(O(n)\).
- Filling the DP table involves \(O(n^2)\) intervals.
- For each interval, the algorithm considers up to \(O(n)\) split points.
- Printing the tree and leaf depths takes \(O(n)\).

Therefore, the overall time complexity is \(O(n^3)\).

**Space Complexity: \(O(n^2)\)**

- DP table: \(O(n^2)\).
- Split table: \(O(n^2)\).
- Weights and prefix sums: \(O(n)\).
- Recursive tree traversal stack: up to \(O(n)\).

Therefore, the overall space complexity is \(O(n^2)\).

## Conclusion
The program uses interval dynamic programming to find the minimum weighted path length of an alphabetic binary tree. The split table enables reconstruction of the optimal tree while preserving the original order of the weights.
