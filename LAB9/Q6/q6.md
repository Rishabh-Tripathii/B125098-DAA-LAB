# README: Reorganize String

## Approach
The program rearranges a string so that identical characters are separated by at least `K` positions.

1. Count the frequency of each lowercase English letter using a frequency array of size 26.
2. At each position, select the available character with the highest remaining frequency.
3. Store characters that still have occurrences remaining in a waiting queue, along with the position at which they become available again.
4. Remove characters from the waiting queue once their waiting period ends.
5. If no valid character is available at any position, return an empty string.
6. If `K <= 1`, return the original string because no additional separation is required.

## Algorithm
1. Read the input string and the value of `K`.
2. Calculate the frequency of every character.
3. Initialize the waiting queue and the result string.
4. For each position in the result:
   - Search all 26 letters.
   - Ignore characters whose frequencies are zero or that are still waiting.
   - Select the available character with the maximum frequency.
   - If no character is available, print an empty string and terminate.
   - Append the selected character to the result and decrease its frequency.
   - If its frequency remains positive, add it to the waiting queue with its next available position.
   - Remove expired entries from the queue.
5. Terminate the result string with `'\0'` and print it.

## Complexity Analysis

**Time Complexity: \(O(n \times 26 \times n)\)**

- Counting character frequencies takes \(O(n)\).
- For each of the \(n\) positions, the algorithm scans 26 characters.
- For each candidate character, it may scan up to \(n\) waiting-queue entries.

Therefore, the overall worst-case time complexity is \(O(26n^2)=O(n^2)\), treating the alphabet size as constant.

**Space Complexity: \(O(n)\)**

- Frequency array: \(O(26)=O(1)\).
- Result string: \(O(n)\).
- Waiting queue: \(O(n)\).

Therefore, the overall auxiliary space complexity is \(O(n)\).

## Conclusion
The program uses a greedy strategy to select the most frequent available character at each position. The waiting queue tracks character restrictions, ensuring that a character is not reused before its required waiting period ends.
