# CANDY DISTRIBUTION PROBLEM USING GREEDY ALGORITHM

1. PROJECT TITLE

---

Candy Distribution Problem Using a Two-Pass Greedy Algorithm in C

2. PROBLEM STATEMENT

---

There are n children standing in a line. Each child has a rating represented by an integer.

The objective is to distribute candies to the children while satisfying the following rules:

1. Every child must receive at least one candy.
2. A child with a higher rating than an adjacent child must receive more candies than that child.

The goal is to determine the minimum total number of candies required to satisfy these conditions.

The program uses a two-pass greedy algorithm to calculate the minimum number of candies required by each child.

---

4. Calculate the minimum total number of candies required.

5. Understand the two-pass greedy technique.

6. ALGORITHM

---

STEP 1: READ INPUT

Read the number of children and their ratings.

If the number of children is less than or equal to zero, display an error message and terminate the program.

STEP 2: INITIALIZE CANDIES

Create a candies array of size n.

Initialize every element to 1 because each child must receive at least one candy.

For example:

Ratings = [1, 2, 2]

Candies = [1, 1, 1]

STEP 3: LEFT-TO-RIGHT PASS

Traverse the ratings array from left to right, starting at index 1.

For each child, compare their rating with the rating of the child immediately to their left.

If:

rating[i] > rating[i - 1]

Then assign:

candies[i] = candies[i - 1] + 1

This ensures that a child with a higher rating than their left neighbor receives more candies.

Example:

Ratings = [1, 2, 3]

Candies after the left-to-right pass:

[1, 2, 3]

STEP 4: RIGHT-TO-LEFT PASS

Traverse the array from right to left, starting at index n - 2.

For each child, compare their rating with the rating of the child immediately to their right.

If:

rating[i] > rating[i + 1]

The current child must receive more candies than the right neighbor.

If the current candy count is not already sufficient, update it:

candies[i] = candies[i + 1] + 1

This ensures that the right-neighbor constraint is also satisfied without unnecessarily increasing candy counts.

Example:

Ratings = [3, 2, 1]

After the left-to-right pass:

Candies = [1, 1, 1]

After the right-to-left pass:

Candies = [3, 2, 1]

STEP 5: CALCULATE TOTAL CANDIES

Add the candy counts assigned to all children.

Formula:

Total Candies = SUM(candies[i])

The program uses long long to store the total.

STEP 6: DISPLAY THE RESULT

Display:

* The ratings of all children.
* The number of candies assigned to each child.
* The minimum total number of candies required.

7. GREEDY STRATEGY

---

The algorithm uses two greedy passes.

The first pass satisfies the constraints involving each child's left neighbor.

The second pass satisfies the constraints involving each child's right neighbor.

Instead of repeatedly adjusting candy counts, the algorithm processes the array twice.

This approach efficiently finds the minimum valid candy distribution in linear time.

10. DRY RUN

---

INPUT:

Ratings = [1, 0, 2, 2, 3]

Number of children = 5

STEP 1: INITIALIZE CANDIES

Every child receives one candy.

Candies = [1, 1, 1, 1, 1]

STEP 2: LEFT-TO-RIGHT PASS

Compare adjacent ratings from left to right.

Index 1:
Rating 0 < Rating 1.
No update.

Candies = [1, 1, 1, 1, 1]

Index 2:
Rating 2 > Rating 0.

candies[2] = candies[1] + 1

Candies = [1, 1, 2, 1, 1]

Index 3:
Rating 2 = Rating 2.
No update.

Candies = [1, 1, 2, 1, 1]

Index 4:
Rating 3 > Rating 2.

candies[4] = candies[3] + 1

Candies = [1, 1, 2, 1, 2]

STEP 3: RIGHT-TO-LEFT PASS

Traverse the array from right to left.

Index 3:
Rating 2 < Rating 3.
No update.

Candies = [1, 1, 2, 1, 2]

Index 2:
Rating 2 > Rating 1.

candies[2] is already greater than candies[3].

No update is required.

Candies = [1, 1, 2, 1, 2]

Index 1:
Rating 0 < Rating 2.
No update.

Candies = [1, 1, 2, 1, 2]

Index 0:
Rating 1 > Rating 0.

candies[0] must be greater than candies[1].

candies[0] = candies[1] + 1

Candies = [2, 1, 2, 1, 2]

STEP 4: CALCULATE TOTAL

Total = 2 + 1 + 2 + 1 + 2

Total = 8

FINAL RESULT

Ratings = [1, 0, 2, 2, 3]

Candies = [2, 1, 2, 1, 2]

Minimum total candies required = 8

11. TIME COMPLEXITY ANALYSIS

---

Let n be the number of children.

A. Initialization

Initializing the candies array requires visiting every child once.

Time Complexity:

O(n)

B. Left-to-Right Pass

The algorithm traverses the array once.

Time Complexity:

O(n)

C. Right-to-Left Pass

The algorithm traverses the array once in reverse order.

Time Complexity:

O(n)

D. Calculating the Total

The algorithm visits every element of the candies array.

Time Complexity:

O(n)

E. Displaying the Results

Printing the ratings and candies requires O(n) time, excluding the time needed to write the output to the console.

OVERALL TIME COMPLEXITY

O(n)

The algorithm performs a constant number of linear traversals, so its time complexity is linear.

12. SPACE COMPLEXITY ANALYSIS

---

The program dynamically allocates two arrays:

1. rating[n] to store the ratings.
2. candies[n] to store the candy counts.

Each array requires O(n) space.

Therefore:

OVERALL SPACE COMPLEXITY: O(n)

2. The program does not check whether scanf() successfully reads every input.

6. CONCLUSION

---

This project demonstrates an efficient solution to the Candy Distribution Problem using a two-pass greedy algorithm.

The first pass processes children from left to right, while the second pass processes them from right to left.

Together, these passes ensure that every child receives at least one candy and that children with higher ratings than their adjacent neighbors receive more candies.

The algorithm finds the minimum total number of candies required in O(n) time and O(n) space.

It provides practical experience with greedy algorithms, array traversal, dynamic memory allocation, and complexity analysis.
