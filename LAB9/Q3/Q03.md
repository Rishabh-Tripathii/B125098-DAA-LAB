# MINIMUM REFUELLING STOPS USING GREEDY ALGORITHM

1. PROJECT TITLE

---

Minimum Refuelling Stops Using a Greedy Algorithm and Max-Heap in C

2. PROBLEM STATEMENT

---

A vehicle needs to travel to a target destination located at distance D.

The vehicle starts with F units of fuel. Each unit of fuel allows the vehicle to travel one unit of distance.

There are n fuel stations along the route. Each station is represented by two values:

* Distance: The station's distance from the starting point.
* Fuel: The amount of fuel available at that station.

The objective is to determine the minimum number of refuelling stops required to reach the target.

If the target cannot be reached, the program returns -1 and displays an appropriate message.

3. OBJECTIVES

---

The main objectives of this project are:

1. Implement a greedy algorithm to solve the minimum refuelling stops problem.

2. Use a max-heap to efficiently select the maximum available fuel.

3. Sort fuel stations by their distance from the starting point.

4. Determine the minimum number of refuelling stops.

5. Handle cases where the destination cannot be reached.

6. Analyze the time and space complexity of the algorithm.

7. Understand the practical application of greedy algorithms and heaps.

6. ALGORITHM

---

STEP 1: READ INPUT

Read the target distance, initial fuel, number of stations, and the distance and fuel values of each station.

Validate the input to ensure that:

* The target distance is non-negative.
* Initial fuel is non-negative.
* The number of stations is non-negative.
* Station distances lie between 0 and D.
* Station fuel amounts are non-negative.

STEP 2: SORT THE STATIONS

Sort all fuel stations in increasing order of their distance from the starting point.

This allows the algorithm to process stations in the order in which they are encountered.

STEP 3: INITIALIZE VARIABLES

Initialize the following variables:

currentFuel = F
currentPosition = 0
stops = 0

Create an empty max-heap to store the fuel amounts available at previously reached stations.

STEP 4: PROCESS EACH STATION

For each station, calculate the distance between the current position and the station.

If the vehicle does not have enough fuel to reach the next station, extract the maximum fuel amount from the max-heap.

Add this fuel to the current fuel and increment the number of stops.

Repeat until the next station is reachable.

If the heap is empty while additional fuel is required, the target cannot be reached.

STEP 5: ADD REACHABLE STATION FUEL

After reaching a station, subtract the distance travelled from the current fuel.

Update the current position.

Insert the station's available fuel into the max-heap.

The fuel is added to the heap because the station has been reached and is now available as a possible refuelling option.

STEP 6: REACH THE TARGET

Treat the target destination as the final point with zero available fuel.

Apply the same process to reach the target.

If successful, return the total number of refuelling stops.

Otherwise, return -1.

7. GREEDY STRATEGY

---

The algorithm follows a greedy strategy.

Whenever the vehicle cannot reach the next station or destination, it chooses the maximum fuel amount among the previously reachable stations.

Why choose the maximum fuel amount?

Choosing the largest available fuel amount provides the greatest increase in travelling range for each required stop.

This strategy minimizes the number of refuelling stops.

The max-heap efficiently maintains and retrieves the largest available fuel amount.

11. TIME COMPLEXITY ANALYSIS

---

Let n be the number of fuel stations.

A. Sorting Stations

The stations are sorted by distance using qsort().

Time Complexity:

O(n log n)

B. Inserting Fuel into the Max-Heap

Each insertion takes O(log n) time.

At most n stations are inserted.

Total Time Complexity:

O(n log n)

C. Extracting Maximum Fuel

Each extraction takes O(log n) time.

At most n fuel values can be extracted.

Total Time Complexity:

O(n log n)

D. Processing Stations

The algorithm processes each station and the target once.

Ignoring heap operations, this takes O(n) time.

OVERALL TIME COMPLEXITY

O(n log n)

The sorting and heap operations dominate the total running time.

12. SPACE COMPLEXITY ANALYSIS

---

The program uses:

1. An array to store the fuel stations: O(n).
2. A max-heap to store available fuel amounts: O(n).
3. An array containing the stations and target point: O(n).

OVERALL AUXILIARY SPACE COMPLEXITY:

O(n)

14. EDGE CASES

---

The algorithm can handle the following cases:

CASE 1: Target is at the starting position.

If D = 0, the target is already reached, so zero stops are required.

CASE 2: Initial fuel is sufficient.

If F >= D, the target can be reached without refuelling.

CASE 3: No fuel stations are available.

If the initial fuel is insufficient to reach the target, the program reports that the target cannot be reached.

CASE 4: A station provides zero fuel.

The station can be reached, but refuelling there does not increase the available fuel.

CASE 5: Target is unreachable.

If the max-heap becomes empty and the vehicle cannot reach the next point, the algorithm returns -1.

CASE 6: Multiple stations have the same distance.

The algorithm processes these stations in sorted order. Since their distances are equal, they do not require additional travel between them.

9. CONCLUSION

---

This project demonstrates how a greedy algorithm and a binary max-heap can solve the Minimum Refuelling Stops problem efficiently.

The algorithm processes stations in increasing order of distance and stores the fuel amounts from previously reached stations in a max-heap.

Whenever the vehicle cannot reach the next point, it selects the largest available fuel amount from the heap.

This strategy minimizes the number of refuelling stops and achieves an overall time complexity of O(n log n).

The project provides practical experience with greedy algorithms, heap operations, sorting, dynamic memory allocation, and algorithmic complexity analysis.
