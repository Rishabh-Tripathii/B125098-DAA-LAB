# MINIMUM COST TO CONNECT ALL STICKS

1. PROJECT TITLE

---

Minimum Cost to Connect All Sticks Using a Greedy Algorithm and Min-Heap in C

2. PROBLEM STATEMENT

---

Given an array of n stick lengths, the objective is to connect all the sticks into a single stick with the minimum total cost.

The cost of connecting two sticks is equal to the sum of their lengths.

After connecting two sticks:

1. The cost of the operation is calculated.
2. A new stick is formed with length equal to the sum of the two connected sticks.
3. The new stick is added back to the collection.

This process continues until only one stick remains.

The goal is to determine the minimum total cost required to connect all the sticks.

3. OBJECTIVES

---

The main objectives of this project are:

1. Implement a greedy algorithm to minimize the total connection cost.

2. Use a binary min-heap to efficiently retrieve the two shortest sticks.

3. Implement heap insertion and minimum extraction operations.

4. Calculate the minimum total cost of connecting all sticks.

5. Handle special cases such as zero or one stick.

6. Analyze the time and space complexity of the algorithm.

7. Understand the applications of greedy algorithms and priority queues.

6. ALGORITHM

---

STEP 1: INITIALIZE THE MIN-HEAP

Insert all stick lengths into a binary min-heap.

The min-heap maintains the smallest stick at its root.

STEP 2: EXTRACT THE TWO SMALLEST STICKS

While more than one stick remains:

1. Extract the minimum stick length, x.
2. Extract the next minimum stick length, y.

STEP 3: CONNECT THE STICKS

Calculate the cost of connecting the two sticks:

cost = x + y

Add this cost to the total cost:

totalCost = totalCost + cost

STEP 4: INSERT THE NEW STICK

The newly connected stick has length:

newLength = x + y

Insert this new length into the min-heap.

The heap is reorganized to maintain the min-heap property.

STEP 5: REPEAT

Continue extracting and connecting the two smallest sticks until only one stick remains.

STEP 6: DISPLAY THE RESULT

Print the accumulated total cost.

This greedy strategy minimizes the total cost of connecting all sticks.

7. GREEDY STRATEGY

---

The algorithm always connects the two shortest available sticks first.

Why?

Connecting shorter sticks earlier prevents their lengths from contributing repeatedly to expensive operations.

A stick formed by connecting two smaller sticks may be connected again later. Therefore, choosing the two smallest sticks at each step minimizes the total accumulated cost.

The min-heap makes it efficient to retrieve the two smallest lengths at every iteration.

11. TIME COMPLEXITY ANALYSIS

---

Let n be the number of sticks.

A. Building the Min-Heap

The program inserts each stick individually.

Each insertion takes O(log n) time.

Total time:

O(n log n)

B. Extracting the Two Minimum Elements

Each iteration extracts two minimum elements.

Each extraction takes O(log n) time.

There are n - 1 connection operations, so the total extraction cost is:

O(n log n)

C. Inserting the Newly Connected Stick

Each connection creates one new stick, which is inserted into the heap.

Each insertion takes O(log n) time.

There are n - 1 connection operations.

Total time:

O(n log n)

OVERALL TIME COMPLEXITY

O(n log n)

This complexity is dominated by the heap insertion and extraction operations.

12. SPACE COMPLEXITY ANALYSIS

---

The program uses a fixed-size array of MAX = 1000 elements to implement the min-heap.

The heap stores the stick lengths and newly formed stick lengths.

The heap requires O(n) space for n sticks.

Therefore:

AUXILIARY SPACE COMPLEXITY: O(1)

The heap itself uses O(n) storage, but it is implemented as a fixed-size global array. Excluding this input-dependent data structure, the algorithm uses O(1) additional variables.

OVERALL SPACE COMPLEXITY: O(n)

18. LIMITATIONS

---

1. The program supports a maximum of 1000 sticks.

2. Negative stick lengths are not allowed.

3. The heap stores values using int, so very large combined lengths may exceed the int range.

4. The program does not check the return value of scanf() for every input operation.

5. The total cost uses long long, but overflow of the total cost is not checked.

6. The program uses a fixed-size global heap array.

7. CONCLUSION

---

This project demonstrates how a greedy algorithm combined with a binary min-heap can solve the Minimum Cost to Connect All Sticks problem efficiently.

At every step, the algorithm connects the two shortest available sticks and inserts their combined length back into the heap.

This strategy minimizes the total connection cost.

The overall time complexity is O(n log n), making the solution efficient for large inputs within the program's supported capacity.

The project provides practical experience with greedy algorithms, priority queues, heap operations, and algorithmic complexity analysis.
