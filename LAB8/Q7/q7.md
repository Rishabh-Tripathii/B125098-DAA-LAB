# Rod Cutting with Reconstruction

## Approach

The problem is solved using **Dynamic Programming**.

For each rod length `i`, all possible first cuts `j` (`1 ≤ j ≤ i`) are considered.

Let:

- `dp[i]` = maximum revenue obtainable from a rod of length `i`
- `cut[i]` = first piece length used in an optimal solution for rod length `i`
- `p[i]` = price of a piece of length `i`

The recurrence is:

\[
dp[i] = \max_{1 \leq j \leq i} \{p[j] + dp[i-j]\}
\]

The base case is:

\[
dp[0] = 0
\]

Along with the maximum revenue, the `cut[]` array stores the first cut that produces the optimal revenue. This allows the exact optimal decomposition to be reconstructed after the DP table is calculated.

## Algorithm

1. Read the rod length `n` and prices `p[1...n]`.
2. Initialize `dp[0] = 0`.
3. For each rod length `i` from `1` to `n`:
   - Consider every possible first cut `j` from `1` to `i`.
   - Calculate:
     \[
     revenue = p[j] + dp[i-j]
     \]
   - If this revenue is greater than the current maximum:
     - Update `dp[i]`.
     - Store `j` in `cut[i]`.
4. `dp[n]` gives the maximum obtainable revenue.
5. Reconstruct the optimal decomposition using `cut[]`:
   - Start with `length = n`.
   - Output `cut[length]`.
   - Set `length = length - cut[length]`.
   - Repeat until `length = 0`.

## Complexity Analysis

### Time Complexity

For every rod length `i`, all possible cuts from `1` to `i` are examined.

\[
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
\]

Therefore, the DP computation takes:

\[
\boxed{O(n^2)}
\]

The reconstruction takes `O(n)` time.

Hence, the overall time complexity is:

\[
\boxed{O(n^2)}
\]

### Space Complexity

The arrays `p[]`, `dp[]`, and `cut[]` each require `O(n)` space.

Therefore:

\[
\boxed{O(n)}
\]

## Final Complexity

| Complexity | Value |
|------------|-------|
| Time | **O(n²)** |
| Space | **O(n)** |
