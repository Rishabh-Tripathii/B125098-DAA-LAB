# Longest Increasing Subsequence (LIS)

## Problem Statement

Given an integer array:

```text
A = [a0, a1, ..., an-1]
```

find the **length of the longest subsequence** such that all elements of the subsequence are **strictly increasing**.

A subsequence does not need to be contiguous, but the relative order of the elements must be preserved.

---

## Approach

The problem is solved using **Dynamic Programming**.

Define:

```text
dp[i]
```

as the length of the **Longest Increasing Subsequence ending at index `i`**.

Every individual element can form an increasing subsequence of length `1`.

Therefore, initially:

```text
dp[i] = 1
```

for every index `i`.

For each element `A[i]`, we examine all previous elements `A[j]`.

If:

```text
j < i
```

and:

```text
A[j] < A[i]
```

then `A[i]` can be added to the increasing subsequence ending at `A[j]`.

---

## Recurrence Relation

For every pair of indices where `j < i` and `A[j] < A[i]`:

$$
dp[i] = \max(dp[i], dp[j] + 1)
$$

The final LIS length is the maximum value in the `dp` array:

$$
\boxed{LIS = \max_{0 \leq i < n} dp[i]}
$$

---

## Algorithm

1. Create a DP array `dp` of size `n`.
2. Initialize every element of `dp` to `1`.
3. For each index `i` from `1` to `n-1`:

   * Examine every previous index `j` from `0` to `i-1`.
   * If `A[j] < A[i]`, update:

$$
dp[i] = \max(dp[i], dp[j] + 1)
$$

4. After calculating all `dp` values, find the maximum value in the array.
5. Return this maximum value as the length of the Longest Increasing Subsequence.

---

## Correctness

The algorithm considers every possible previous element for each `A[i]`.

If `A[j] < A[i]`, then `A[i]` can extend the increasing subsequence that ends at `A[j]`.

Since `dp[j]` stores the longest increasing subsequence ending at `A[j]`, the value:

$$
dp[j] + 1
$$

represents the length obtained by adding `A[i]`.

Taking the maximum over all valid previous elements ensures that `dp[i]` stores the longest increasing subsequence ending at `A[i]`.

Finally, the longest increasing subsequence can end at any position, so the maximum value among all `dp[i]` values is the required answer.

---

## Complexity Analysis

Let:

* `n` = number of elements in the array.

For every element, the algorithm checks all previous elements.

The nested loops therefore perform at most approximately:

$$
\frac{n(n-1)}{2}
$$

comparisons.

### Time Complexity

$$
\boxed{O(n^2)}
$$

### Space Complexity

The algorithm uses a DP array containing `n` elements.

$$
\boxed{O(n)}
$$

---

## Complexity Summary

| Resource | Complexity |
| -------- | ---------- |
| Time     | **O(n²)**  |
| Space    | **O(n)**   |

---

## Key Points

* Uses **Dynamic Programming**.
* `dp[i]` represents the LIS length **ending at index `i`**.
* Every element initially has an LIS length of `1`.
* Only previous elements smaller than the current element can extend the subsequence.
* The recurrence is:

$$
\boxed{dp[i] = \max(dp[i], dp[j] + 1)}
$$

where:

$$
j < i \quad \text{and} \quad A[j] < A[i]
$$

* The final answer is:

$$
\boxed{\max(dp[i])}
$$

* Time complexity: **O(n²)**.
* Space complexity: **O(n)**.
