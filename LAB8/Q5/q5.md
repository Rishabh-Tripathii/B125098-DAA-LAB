# Maximum Sum Increasing Subsequence (MSIS)

## Problem Statement

Given an array of `n` positive integers:

```text
A = [a0, a1, ..., an-1]
```

find the **maximum possible sum of a strictly increasing subsequence**.

A subsequence does not need to be contiguous, but the relative order of the elements must be preserved.

A subsequence is strictly increasing if:

$$
a_{i_1} < a_{i_2} < a_{i_3} < \cdots
$$

---

## Approach

The problem is solved using **Dynamic Programming**.

Define:

```text
dp[i]
```

as the **maximum sum of a strictly increasing subsequence ending at index `i`**.

Every individual element can form an increasing subsequence by itself. Therefore, the initial value is:

```text
dp[i] = A[i]
```

For each element `A[i]`, examine all elements before it.

If:

```text
j < i
```

and:

```text
A[j] < A[i]
```

then `A[i]` can be added to the increasing subsequence ending at `A[j]`.

---

## Recurrence Relation

For every valid pair of indices where:

$$
j < i
$$

and:

$$
A[j] < A[i]
$$

the recurrence is:

$$
\boxed{dp[i] = \max(dp[i], dp[j] + A[i])}
$$

The final answer is the maximum value in the `dp` array:

$$
\boxed{\text{Answer} = \max_{0 \leq i < n} dp[i]}
$$

---

## Algorithm

1. Create a DP array `dp` of size `n`.
2. Initialize:

```text
dp[i] = A[i]
```

for every index `i`.
3. For each index `i` from `1` to `n-1`:

* Examine every previous index `j` from `0` to `i-1`.
* Check whether:

$$
A[j] < A[i]
$$

4. If the condition is satisfied, update:

$$
dp[i] = \max(dp[i], dp[j] + A[i])
$$

5. After processing all elements, find the maximum value in `dp`.
6. This maximum value is the maximum sum of a strictly increasing subsequence.

---

## Correctness

The algorithm considers every possible element that can precede `A[i]` in an increasing subsequence.

If `A[j] < A[i]`, then the subsequence represented by `dp[j]` can be extended by `A[i]`. Its resulting sum is:

$$
dp[j] + A[i]
$$

Taking the maximum over all valid previous indices ensures that `dp[i]` represents the maximum possible sum of an increasing subsequence ending at `A[i]`.

Since the optimal subsequence may end at any index, taking the maximum value among all `dp[i]` gives the overall maximum sum.

---

## Complexity Analysis

Let:

* `n` = number of elements in the array.

For every element, the algorithm checks all previous elements.

The number of comparisons is approximately:

$$
\frac{n(n-1)}{2}
$$

### Time Complexity

$$
\boxed{O(n^2)}
$$

### Space Complexity

The algorithm uses a DP array containing `n` elements.

$$
\boxed{O(n)}
$$

---

## Complexity Summary

| Resource | Complexity |
| -------- | ---------- |
| Time     | **O(n²)**  |
| Space    | **O(n)**   |

---

## Key Points

* Uses **Dynamic Programming**.
* `dp[i]` stores the maximum sum of an increasing subsequence **ending at index `i`**.
* Every element initially forms a subsequence with sum `A[i]`.
* A previous element can be included only when:

$$
A[j] < A[i]
$$

* The recurrence is:

$$
\boxed{dp[i] = \max(dp[i], dp[j] + A[i])}
$$

* The final answer is:

$$
\boxed{\max(dp[i])}
$$

* Time complexity: **O(n²)**.
* Space complexity: **O(n)**.

---

## Difference from Longest Increasing Subsequence

The structure of MSIS is similar to LIS, but the DP value represents a different quantity.

| Problem | DP Meaning     | Update         |
| ------- | -------------- | -------------- |
| LIS     | Maximum length | `dp[j] + 1`    |
| MSIS    | Maximum sum    | `dp[j] + A[i]` |

Thus, LIS maximizes the **number of elements**, while MSIS maximizes the **sum of elements**.
