# Edit Distance with Traceback Information

## Approach

The problem is solved using **Dynamic Programming**.

Let:

- `dp[i][j]` = minimum number of operations required to transform the first `i` characters of string `A` into the first `j` characters of string `B`.
- `parent[i][j]` = operation used to obtain the optimal solution, which is used for traceback.

The allowed operations are:

- **Insertion**
- **Deletion**
- **Substitution**

If the current characters are equal:

\[
dp[i][j] = dp[i-1][j-1]
\]

Otherwise:

\[
dp[i][j] =
1 + \min
\begin{cases}
dp[i-1][j] & \text{Deletion}\\
dp[i][j-1] & \text{Insertion}\\
dp[i-1][j-1] & \text{Substitution}
\end{cases}
\]

The base cases are:

\[
dp[i][0] = i
\]

\[
dp[0][j] = j
\]

The `parent[][]` table stores the operation selected for each state. This allows the exact sequence of operations to be reconstructed by tracing backwards from `dp[m][n]` to `dp[0][0]`.

## Algorithm

1. Read strings `A` and `B`.
2. Let their lengths be `m` and `n`.
3. Initialize the first row and first column:
   - `dp[i][0] = i`
   - `dp[0][j] = j`
4. For every `i` from `1` to `m` and `j` from `1` to `n`:
   - If `A[i-1] == B[j-1]`, copy `dp[i-1][j-1]` and store `MATCH`.
   - Otherwise calculate the costs of insertion, deletion, and substitution.
   - Select the minimum cost and store the corresponding operation in `parent[i][j]`.
5. `dp[m][n]` gives the minimum edit distance.
6. Start traceback from `(m,n)`.
7. Follow the operations stored in `parent[][]` until `(0,0)` is reached.
8. Reverse the collected operations to obtain the transformation sequence.

## Complexity Analysis

### Time Complexity

There are `(m + 1)(n + 1)` DP states, and each state takes constant time to calculate.

\[
\boxed{O(mn)}
\]

The traceback requires:

\[
O(m+n)
\]

Therefore, the overall time complexity is:

\[
\boxed{O(mn)}
\]

### Space Complexity

The `dp[][]` and `parent[][]` tables each require `O(mn)` space.

Therefore:

\[
\boxed{O(mn)}
\]

Additional space for storing the traceback operations is `O(m+n)`, which does not change the overall complexity.

## Final Complexity

| Complexity | Value |
|------------|-------|
| Time | **O(mn)** |
| Space | **O(mn)** |
